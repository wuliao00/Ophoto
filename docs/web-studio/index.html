📱 Android 原生工程架构（Kotlin + Compose + Camera2 + GLES3）

本仓库根工程为完整的 Android 原生相机应用 com.ophoto（minSdk 26 / targetSdk 35），采用五层解耦架构：
• CameraX + Camera2Interop 引擎：动态枚举 OPPO / OnePlus / realme 物理超广角、主摄、潜望长焦焦段与真实 ISO / 快门纳秒 / 色温 RGGB 增益范围。
• OpenGL ES 3.0 3D LUT 实时着色器：零拷贝 samplerExternalOES + 硬件三线性插值 sampler3D + Sobel 峰值对焦 + 96% 斑马纹。
• 沙盒安全滤镜导入器：支持 .cube、.filterpack、manifest.json、OPHOTO1: 离线口令二维码及社区预设 JSON 兼容导入。

🔒 ColorOS / OxygenOS 专属适配与隐私守则

• 大师参数半透明悬浮窗：MasterOverlayService 支持标准参数卡、紧凑胶囊、迷你悬浮球三种形态，可直接在系统原生相机「大师模式」上方左右滑动参考参数。
• 受限设置解锁指引：若 ColorOS 14–17 拦截侧载 APK 悬浮窗授权，前往「系统设置 → 应用管理 → Ophoto → 右上角 ⋮ → 解除受限设置」即可一键开启。
• 零上传本地优先：所有照片渲染、滤镜库（Room 数据库）与 EXIF GPS 位置抹除均在设备本地离线完成。
